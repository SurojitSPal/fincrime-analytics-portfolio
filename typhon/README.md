# TYPHON — Hybrid Rules + ML + GenAI Alert Triage and SAR Drafting

**Status: scoped and dataset generated** — 5,000-row labelled synthetic dataset produced (98 accounts, PostgreSQL schema, reproducible generator).

## What it is

An alert-triage and SAR (Suspicious Activity Report)-drafting framework combining three layers:

1. **SQL rules-based monitoring layer** — deterministic typology detection
2. **Python ML scoring layer** — scikit-learn classification plus NetworkX graph analytics and autoencoder-based anomaly detection, scoring and ranking alerts the rules layer surfaces
3. **GenAI layer** — drafts SAR narratives and typology classification rationale from the scored, investigated alert

Visualised through a Tableau risk-operations dashboard.

## Dataset

A 5,000-row labelled synthetic AML dataset with typology injection, generated by a purpose-built, reproducible generator against a PostgreSQL schema. This generator is the shared foundation for the portfolio's synthetic data lineage: [THEMIS](../themis) extends it into a larger, purpose-shaped derivative dataset, and [NEMESIS](../nemesis) red-teams the detection logic trained on it.

No real transaction or complaint data is used anywhere in TYPHON — see [`docs/DATA-GOVERNANCE.md`](../docs/DATA-GOVERNANCE.md).
